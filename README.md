# TempConvAllMB
## Description: 
This R package provides functions to convert temperatures between Fahrenheit, Celsius, and Kelvin.

## Functions: 
F_to_C(): Converts Fahrenheit to Celsius.

C_to_F(): Converts Celsius to Fahrenheit.

F_to_K(): Converts Fahrenheit to Kelvin.

K_to_F(): Converts Kelvin to Fahrenheit.

C_to_K(): Converts Celsius to Kelvin.

K_to_C(): Converts Kelvin to Celsius.

## Examples:
F_to_C(29)

C_to_F(27)

F_to_K(52)

K_to_F(297)

C_to_K(33)

K_to_C(275)

All functions can also accept a vector of temperatures as an input.
